# Zomato-Restaurant-Analysis
Performed end-to-end data processing and EDA using Python, SQL, and Power BI, derived global business insights regarding restaurant performance and pricing strategies.

## Project Overview :
This project involves a comprehensive analysis of Zomato’s global
restaurant data. The primary goal is to perform end-to-end data
processing—from raw data cleaning to advanced feature
engineering—to derive business insights using different Analytics tool
(Python,SQL,Power BI) regarding restaurant performance, pricing
strategies, and consumer preferences across different countries.

## Project Objectives :
● To standardize multi-currency data into a single currency (INR) for
global comparison.

● To clean and normalize complex "wide-format" cuisine data into a
usable format.

● To identify high-performing restaurant segments based on ratings
and costs.

● To create a robust, analysis-ready dataset for an interactive Power
BI dashboard.
